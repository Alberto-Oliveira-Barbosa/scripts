# Scripts Python Úteis

[![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)](https://www.python.org/)

Uma coleção de scripts Python para automatizar tarefas do dia a dia, praticar conceitos de programação e resolver problemas comuns. Este repositório serve como um baú de ferramentas pessoal e um portfólio de aprendizado.

## Scripts Disponíveis

### Organização e Sistema
*   **`organizador_arquivos.py`**: Organiza automaticamente os arquivos de um diretório, movendo-os para pastas categorizadas por extensão (ex: PDFs, imagens, planilhas). Ideal para limpar pastas como a de *Downloads*.
*   **`verifica_arquivos_duplicados.py`**: Encontra e lista arquivos duplicados em uma pasta com base no seu conteúdo (hash MD5), ajudando a liberar espaço em disco.
*   **`get_Information_System.py`**: Exibe informações úteis sobre o sistema operacional, hardware e redes, funcionando como um comando `systeminfo` ou `neofetch` simplificado.

### Criptografia e Conceitos
*   **`criptografiaBasica.py`**: Demonstra métodos de criptografia simétrica básica, como a Cifra de César, para fins educacionais.
*   **`Map filter reduce - exercicios.ipynb`**: Exercícios práticos sobre as funções `map`, `filter` e `reduce`, essenciais para programação funcional em Python.
*   **`fatorial.py`**: Calcula o fatorial de um número de diferentes formas (iterativa e recursiva), um exemplo clássico de lógica de programação.
